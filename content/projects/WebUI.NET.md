.NET/C# Wrapper for the WebUI browser based GUI library

# [WebUI.NET](https://github.com/Juff-Ma/WebUI.NET)

Writing a good looking UI natively is difficult but frameworks like Electron draw in heavy dependencies that are seen unfavoribly by many people.

[WebUI](https://webui.me) tries to solve this by using the user's browser to display the UI. WebUI.NET includes high level bindings of WebUI for .NET.

It allows fot building good looking UIs using web technologies and the powerful C# language as backend. All in a cross platform supported way.
